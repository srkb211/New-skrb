# 架空地図アトラス（Fantasy Atlas）

指やマウスで描いた大まかな陸地の形から、**リアルな海岸線・山地・河川・平野**を自動生成し、
その上に**架空の国と行政区画（州・県）**を描いたり自動で作ったりできる、ブラウザで動く地図エディタです。
スマートフォン（タッチ）とパソコン（マウス・ペン）の両方で使えます。サーバーは不要です。

## できること

| 機能 | 内容 |
| --- | --- |
| 下絵を描く | 輪郭ペン・陸ブラシ・海ブラシ・線消し。**塗りつぶし**で囲んだ範囲を陸／海にできます（輪郭の小さな切れ目は「隙間閉じ」で自動的に塞ぎます） |
| 地形の自動生成 | 下絵の形を保ったまま、フラクタルノイズで湾・半島・沖合の島を作って海岸線を複雑にし、標高グリッド・河川・湖を生成します |
| 山地・河川・平野の初期案 | 標高と起伏から 平野／丘陵／高原／山地／高山 に区分し、**山脈・山地・主な山・河川・平野・盆地・高原・湖**を抽出して名前を付けます（地物タブに一覧） |
| 山脈ペン | 山脈を通したい所に線を引くと、その周辺の地形だけがすぐ作り直されます |
| 国境・州境の編集 | 国境ペン・州境ペン・境界消し。線の端は近くの海岸や他の境界線に自動でつながり、区画の境目は描いた線に沿います（線のどちら側にもずれません）。届いていない線の端は赤い丸で示し、区画が分かれなかったときは理由を表示します。海の上に引いた国境線で小島の所属も決められます |
| 領土ブラシ・統合 | 国（州）の中から描き始めてなぞると、その範囲がその国（州）の領土になり、国境は塗った形に合わせて引き直されます。新しい国も塗って作れます。区画選択のカードから隣国（隣の州）を統合できます |
| 行政区画ポリゴンの自動生成 | 境界線で囲まれた範囲が自動で「国」「州」になり、隣同士で辺を共有するポリゴン（隙間・重なりなし）を組み立てます |
| 隣接関係と面積 | 国・州ごとの面積、海岸線の長さ、隣接する区画と共有する境界の長さを計算します（データタブ、GeoJSON 書き出し） |
| 架空の国の自動生成 | 山脈・大河・急斜面を越えにくいように領域を広げるので、地形に沿った国境ができます。国名・政体・首都・州名は既定では西洋系の命名文化（ラテン風・ゲルマン北欧風・スラヴ風・英国ケルト風・ギリシャ風）だけから生成します（「生成」タブで変更可） |
| 部分再生成 | 「範囲選択」で囲んだ所だけ海岸線・地形を作り直して周囲となめらかにつなぎます。国ごとに州だけを作り直すこともできます |
| 名前の編集 | 国名・政体・首都名・区画の呼び名・州名・中心都市名は「区画選択」のカードで、山脈・山・川・平野・湖などの地物名は「地物」タブで書き換えられます（空にすると自動の名前に戻ります） |
| 首都・中心都市の位置 | 区画選択のカードで「地図で指定」を押し、国（州）の中をタップして位置を決めます |
| 気候 | 気候計算用グリッドで、緯度相当に基づく日射・気温、標高による気温低下、海からの距離による季節変動、卓越風と山脈による降水を近似し、年平均気温・年間降水量・季節性・ケッペン気候区分・バイオームを求めます（「気候」タブ） |
| 保存と再読込 | **「画像DL」で PNG 画像としてダウンロード**。画像の中に地図データ一式が埋め込まれているので、「開く」でその PNG を選べば続きから編集できます。ブラウザ内への保存・自動保存もあります |

## 使い方

1. 「輪郭ペン」で陸地の形を描き、「塗りつぶし」で内側をタップして陸にします（陸ブラシで直接塗っても構いません）。
2. 画面下の「地形を生成」を押すと、海岸線が複雑になり、山地・河川・平野ができます。
   生成の細かさ（海岸線の複雑さ、山地の多さ、最高標高、侵食、河川の密度、シード）は「生成」タブで調整できます。
3. 「国境ペン」「州境ペン」で境界を描くか、「生成」タブの「国と州を自動生成」を押します。形を直したいときは「領土ブラシ」で国の中からなぞって塗り広げます。
4. 「区画選択」で国や州をタップすると、名前・政体・首都・色の変更、面積や隣国の確認、州の作り直し、島の編入などができます（同じ国をもう一度タップすると州を選択）。
5. 気に入らない所は「範囲選択」で囲み、「生成」タブの「選択範囲を再生成」で作り直します。
6. 「画像DL」で PNG を保存します。後で「開く」→「画像ファイル（PNG）から開く」で読み込めます。

### 操作

- 拡大・縮小：2 本指のピンチ／マウスホイール／右下の ＋ − ボタン
- 移動：「移動」ツール、2 本指ドラッグ、右ドラッグ、スペース＋ドラッグ
- 元に戻す・やり直す：上部のボタン、`Ctrl+Z` / `Ctrl+Shift+Z`（`Ctrl+Y`）
- `Esc`：範囲選択・区画選択の解除

### 保存データについて

- ダウンロードした PNG には、独自チャンク（`fmAp`）として下絵・地形（海岸線の場と標高）・山脈ガイド・国境/州境・国と州の名前などが圧縮して埋め込まれます。
- 画像を加工・再圧縮（JPEG への変換、SNS への投稿など）するとデータは失われます。保存用には元の PNG を残してください。
- 標高は 1cm 単位で可逆に保存されるため、読み込み後の河川や地物は保存前とまったく同じになります。
- 「保存」はブラウザ内（IndexedDB）に保存します。編集内容は自動保存され、次に開いたとき復元されます。
- 行政区画ポリゴンは「データ」タブから GeoJSON（座標は km 単位の平面座標）でも書き出せます。

## 気候モデル（近似）

「気候」タブで計算・表示・設定を行います。地形を生成・部分再生成すると自動で計算し直し、設定を変えたときは「気候を再計算」を押します。

### 座標系の分離（世界設定）

地図の座標（左上からのセル・km）と、気候計算に使う **緯度相当** は別物です。Y 座標を緯度とはみなさず、世界設定の次の値から各地点の緯度相当を線形に求めます。

| 設定 | 意味 |
| --- | --- |
| 中心の緯度相当 | 地図の中心がどの緯度に相当するか（北が正） |
| 北相当の向き | 地図の上から時計回りの角度（90 なら地図の右が北相当） |
| 緯度 1 度の距離 | 地球は約 111 km。小さくすると同じ地図でも緯度の幅が広がる |
| 地軸の傾き | 季節変化の大きさ（地球は 23.44°） |

### 計算の流れ

1. 地形を **気候グリッド**（既定は地形 2×2 セルで 1 セル）に集約し、陸の割合と平均標高を求める
2. 緯度相当と地軸の傾きから月ごとの大気上端の日射量を求め、地球の緯度帯別の年平均気温に合わせた折れ線で気温に換算
3. 標高 × 気温減率（既定 6.5 °C/km）で気温を下げる
4. 海からの距離（風上側を重視）で季節の振れ幅を海洋性〜大陸性に変える。高緯度の海沿いは海の効果で少し暖める
5. 卓越風（緯度帯モデル：貿易風・偏西風・極東風、または固定風向）で水蒸気を運び、距離・上り斜面・低温で雨にする。山を越えた風下は乾く（雨陰）。夏・冬で降水帯を南北にずらして 2 季節分を計算
6. 月別の気温と（半年ごとの降水から近似した）月別降水から、ケッペン気候区分を判定。気候区分・年降水量・年平均気温・標高からバイオームを決める

分類の閾値（A/C/D の境、乾燥限界の係数と補正、s/w の判定、a/b/c/d、草原や雨林になる降水量など）はすべて「分類の条件」で変更できます。

### 保存される値と単位

| 項目 | 単位・形式 |
| --- | --- |
| セル ID・位置 | ID = iy × 幅 + ix。セル中心の地図座標（地形セル）と km、緯度相当（度）は書き出し時に算出 |
| 年平均気温・最暖月・最寒月 | °C（0.01 °C 単位） |
| 年間降水量 | mm/年（1 mm 単位） |
| 季節性 | 気温の年較差（°C）、夏半年の降水割合 0〜1 と降水の季節性指数 0〜1 |
| 気候区分 / バイオーム | ケッペン記号（Af〜EF の 31 種）/ 16 種のバイオーム |
| 生成方式とバージョン | 気候：`fantasy-atlas/climate-energy-advection` v1.0.0、地形：`fantasy-atlas/terrain-fbm-streampower` v1.0.0。シード・設定・計算日時・地形の指紋・検証結果も記録 |

同じ地形・設定・シードなら同じ結果になります（局所的なゆらぎもシードで決まります）。保存・読み込みで値は変わりません。
「CSV（陸のみ／海を含む）」で気候グリッドを書き出せます（先頭の `#` 行にバージョン・単位・前提を記載）。

### 検証

欠損（配列の欠け・長さの不一致）、無効値（NaN・無限大）、範囲外の値（気温 −90〜60 °C、降水 0〜15000 mm、割合 0〜1、不正な区分コード）、
最暖月・年平均・最寒月の大小関係の矛盾、陸なのに未分類の地点、範囲外の設定値（丸めて使用）、±90° を超える緯度相当を検出し、「データの検証」に表示します。ファイル読み込み時にも同じ検査を行います。

### 前提と限界

これは架空世界づくりのための大まかな近似であり、気象・気候の予測ではありません。

- 惑星の丸さによるゆがみ、海流、氷雪や雲による反射、季節の遅れ（最暖月の遅れ）、モンスーンなどの季節風循環、気圧配置は扱いません
- 卓越風は単純な帯状の場で、地図の外は海とみなします
- 降水は単純な水蒸気輸送モデルで、月別降水は半年ごとの合計から正弦波で配分した近似値です
- 河川の流量は今のところ降水量を反映していません（地形のみから計算）

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # 単体テスト（vitest）
npm run build    # 型チェック＋本番ビルド（dist/）
```

GitHub Pages で公開する場合は、リポジトリの Settings → Pages → Source を「GitHub Actions」にしてください。
`main` ブランチへの push で `.github/workflows/deploy.yml` がビルドして公開します。

### 構成

```
src/core/      地図データと生成アルゴリズム（DOM に依存しない純粋な処理）
  coast.ts       符号付き距離＋ドメインワープした fBm による海岸線の複雑化
  terrain.ts     標高生成（大陸のうねり・山脈帯の尾根ノイズ・山脈ガイド）と河川侵食
  hydrology.ts   Priority-Flood による窪地処理・流向・流量累積、河川の折れ線化、湖
  landforms.ts   地形区分と山脈・河川・平野などの地物抽出
  political.ts   境界線から国・州を求める処理、面積・隣接・海岸線の統計
  topology.ts    ラベル格子 → 共有弧（arc）→ 区画ポリゴンの組み立て
  autogen.ts     地形コスト付きダイクストラ法による架空の国・州の自動生成
  names.ts       架空の地名・国名の生成
  geoframe.ts    地図座標と緯度相当座標の対応（世界設定）
  climate.ts     気候モデル（気温・降水・季節性・気候区分・バイオーム・検証）
  serialize.ts   保存形式（zlib 圧縮）と PNG への埋め込み
src/worker/    重い生成処理を Web Worker で実行
src/app/       画面（キャンバス描画・入力・パネル・保存）
tests/         単体テスト
```
